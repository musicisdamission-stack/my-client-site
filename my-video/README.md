# Make It Big (music video)

Remotion project that renders an audio-reactive lyric video for "Make It Big".

- `MakeItBig`: 1920×1080 (YouTube)
- `MakeItBigVertical`: 1080×1920 (TikTok / Reels / Shorts)

## Assets (not committed)

The song, cover art and timed lyrics are gitignored because this repo is public. Put them here before rendering:

- `public/make-it-big.mp3`
- `public/cover.jpg` (e.g. extracted from the MP3: `npx remotion ffmpeg -i public/make-it-big.mp3 -an -c:v copy public/cover.jpg`)
- `src/data/lyrics.json` (generated by the scripts below)

## Lyric timing

1. `pip install faster-whisper`
2. `python3 scripts/transcribe.py medium.en public/make-it-big.mp3`
3. `python3 scripts/align.py words_medium.en.json src/data/lyrics.json lyrics.txt`

`align.py` contains hand-set anchors (verse 2 opening, "MAKE IT BIG" chant times) for spots Whisper got wrong.

## Commands

- `npm run dev`: preview in Remotion Studio
- `npx remotion render MakeItBig out/make-it-big-16x9.mp4`
- `npx remotion render MakeItBigVertical out/make-it-big-9x16.mp4`
